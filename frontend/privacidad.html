Información para usuarios

Política de privacidad

Este aviso explica qué información usa SmartCity Cloud y para qué. SmartCity Cloud es un proyecto universitario demostrativo de monitoreo urbano e IoT.

Última actualización: 29 de octubre de 2026

Responsable y contacto

El contacto del proyecto es Richard Ruiz. Para consultas sobre privacidad, acceso, corrección o eliminación de datos, escribe a richard.ruizvuni@gmail.com.

Información que se procesa

  • Cuenta e inicio de sesión: nombre, correo electrónico, identificador de la cuenta y, cuando el proveedor lo entrega, imagen de perfil. Puedes iniciar sesión mediante Facebook, Google o correo electrónico. La contraseña del proveedor social no se comparte con SmartCity Cloud.
  • Perfil y uso del sistema: rol, estado del perfil, preferencias y registros técnicos necesarios para mantener el acceso, proteger la plataforma y auditar acciones administrativas.
  • Mensajes a Brunito: el texto que escribes y, cuando hace falta para responder sobre el estado de la ciudad, lecturas pertinentes de sensores. El código actual conserva el historial de Brunito temporalmente en la sesión del navegador y lo envía al servicio de Gemini para generar respuestas; no lo guarda como historial de chat en la base de datos propia.
  • Datos ambientales y de demostración: lecturas de sensores disponibles en el tablero. Mientras el ESP32 no esté conectado, algunos valores son simulados o de prueba y no representan necesariamente mediciones físicas.
  • Clima: cuando consultas el clima, se envía a Open-Meteo la ubicación seleccionada para obtener condiciones meteorológicas.

Para qué se usan

La información se usa para autenticarte, mostrar tu perfil y sus permisos, operar las vistas del tablero, presentar datos y responder a tus consultas. SmartCity Cloud no vende datos personales ni los usa para publicidad dirigida.

Proveedores que ayudan a operar el servicio

  • Supabase procesa la autenticación y aloja los datos de la aplicación.
  • Vercel sirve el sitio web y Render aloja el backend.
  • Meta/Facebook y Google pueden participar en el inicio de sesión si eliges esos proveedores.
  • Google Gemini recibe el mensaje de Brunito y el contexto pertinente para generar una respuesta. No escribas contraseñas, tokens ni información confidencial en el chat. Si la API se usa con cuota gratuita, Google indica que puede usar las entradas y respuestas para mejorar sus productos y que revisores humanos podrían procesarlas; en servicios pagados, se aplican condiciones distintas. El tratamiento depende del plan configurado para la API. Consulta los términos de Gemini API.
  • Open-Meteo recibe la ubicación solicitada para consultar el clima.

Estos servicios procesan la información necesaria para prestar sus funciones conforme a sus propias condiciones y políticas: Supabase, Google, Facebook, Vercel y Render.

Conservación y eliminación

Los datos de perfil se mantienen mientras la cuenta esté activa. Puedes solicitar su eliminación siguiendo las instrucciones de eliminación de datos. Algunos registros técnicos, de auditoría o de operación pueden conservarse sin el vínculo directo al perfil cuando sean necesarios para la seguridad o para mantener el historial del sistema. Las copias técnicas pueden seguir los ciclos de conservación de los proveedores.

Seguridad y derechos

El acceso a la aplicación requiere autenticación y se controla mediante roles. Ningún servicio conectado puede garantizar seguridad absoluta. Puedes solicitar información, corrección o eliminación de datos escribiendo al contacto indicado. También puedes retirar a SmartCity Cloud el permiso de Facebook desde la configuración de aplicaciones de Facebook; eso revoca el acceso social, pero no sustituye la solicitud de eliminación de la cuenta SmartCity.

Si cambian las funciones, los proveedores o los datos tratados, esta página se actualizará. Revisa la fecha indicada al inicio.
